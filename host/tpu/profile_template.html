Where the cycles go

By matrix

Every program for that matrix, summed. MM efficiency is the ideal (tiles × max(m, N) plus one N-cycle preload per MATMUL) over the cycles MM held each MATMUL. Host gap is the time before the program's first dispatch with the core idle: the ARM's own work and its pushes.

By mark

Marks are what the host was doing (a prompt chunk, a decoded token). Wall time is the ARM's clock between marks; core time is the core's cycles at 50 MHz.
